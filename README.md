# 貨架[填單] 庫存掃描 Web App 部署指南

本專案完全由 **Google Apps Script (GAS)** 原生驅動，免自架伺服器，直接存取並讀寫試算表中的「貨架[填單]」。

## 試算表欄位對應（A ~ G）
- **A 欄**：日期 (格式如: `2026-09-13 16:30:00`，自動取得當前時間)
- **B 欄**：料號 (相機掃描 QR Code 或手動輸入)
- **C 欄**：數量 (正整數，有 +/- 按鈕輔助)
- **D 欄**：儲位 (相機掃描 QR Code 或手動輸入)
- **E 欄**：進或出 (`進` 或 `出`)
- **F 欄**：經辦人 (本機自動記憶上次輸入的姓名/工號)
- **G 欄**：備註 (批號、單號、工令等)

## 3 分鐘部署步驟

### 步驟 1：開啟試算表的指令碼編輯器
1. 用瀏覽器開啟您的 Google 試算表：
   `https://docs.google.com/spreadsheets/d/1dryNf2mvqdfBiFuztLocqmsxml2PUAqT-W8mVapWHcc/edit?gid=312702075#gid=312702075`
2. 點擊頂部功能表的 **「擴充功能」 (Extensions) -> 「Apps Script」**。

### 步驟 2：貼上程式碼
1. 在左側檔案清單中，點擊 `程式碼.gs`（或 `Code.gs`），將裡面的內容替換為本專案的 [Code.gs](./Code.gs) 全文。
2. 點擊左側「檔案」旁邊的 **「+」號 -> 選擇「HTML」**，將檔案名稱命名為 **`index`**（會自動產生 `index.html`）。
3. 將本專案的 [index.html](./index.html) 內容全部複製並貼入該 `index.html` 檔案中。
4. 點擊上方的 **「儲存專案」 (磁碟圖示)**。

### 步驟 3：發布為網頁應用程式 (Web App)
1. 點擊右上角藍色按鈕 **「部署」 (Deploy) -> 「新增部署作業」 (New deployment)**。
2. 點擊左側齒輪圖示，選擇 **「網頁應用程式」 (Web app)**。
3. 設定內容如下：
   - **說明**：`庫存條碼掃描 App`
   - **執行身分 (Execute as)**：選擇 **「我」 (Me)**
   - **誰可以存取 (Who has access)**：
     - 如果內部同仁皆有 Google Workspace 帳號，可選「您機構中的任何人」。
     - 若希望現場手機直接開無障礙，可選 **「所有人」 (Anyone)**。
4. 點擊 **「部署」**。
5. 首次部署需點擊 **「審查權限」 (Review Permissions)**，選擇您的 Google 帳號並允許存取試算表。
6. 部署完成後，會獲得一串 **「網頁應用程式網址」 (Web App URL)**。

## 手機現場操作方式

1. 將網頁應用程式網址轉成 QR Code，或直接透過 LINE / 通訊軟體傳到現場作業員的手機。
2. 以手機瀏覽器（iOS Safari 或 Android Chrome）開啟網址。
3. **連續掃描流程**：
   - 選擇 **進庫** 或 **出庫 (扣帳)**。
   - 點擊「掃碼」按鈕，對準料號 QR Code。
   - 掃描成功後，系統自動回傳該料號在所有儲位的目前即時結存，並自動接續開啟「儲位」掃描。
   - 對準貨架上的儲位 QR Code。
   - 輸入數量，點擊 **「確認送出」**。
   - 資料立即即時追加至試算表「貨架[填單]」A~G 欄，並在下方動態列出歷史異動！
